# defensive-performance-dashboard
The goal of this project is to create a Defensive Performance Dashboard that helps coaches prepare their team for the following game by identifying defensive strengths, weaknesses, and recurring tactical patterns.
# Decision-Making Problem
The dashboard is designed to help coaches decide how to adjust their defensive strategy for the next game, including pressing height, defensive shape, and transition defending.
# Proposed Analytics Approach
The dashboard would combine match video analysis with GPS and tracking data to help coaches make better decisions about the team’s defensive strategy. It would analyze pressing, defensive shape, defensive transitions, tackles, interceptions, and other key defensive actions.
# Use by Decision Makers
Coaches would use the dashboard after each match during post-game video sessions and again before upcoming matches. This would help them make appropriate decisions about tactics, defensive strategy, and formation based on the trends identified in the data.
# Connection to Chapter 7
This project is currently in the creative phase because the main idea, purpose, data sources, and use by coaches are still being defined. The dashboard has not yet been fully tested or implemented.
